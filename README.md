# 🛒 E-Shopping Web Application

A complete E-Commerce web application built with **Angular (frontend)** and **.NET Core (backend)**, integrated with **MongoDB** for data storage.  
This project is designed as a template for online shopping platforms — fully customizable for any product type.

---

## ✨ Features

- ✅ User-friendly e-commerce storefront  
- ✅ Product listing with categories and search  
- ✅ Shopping cart and checkout flow  
- ✅ Basic order management system  
- ✅ Example payment flow (demo only, **not real payment**)  
- ✅ Built with maintainable, clean code (frontend + backend)  
- ✅ Cloud-ready architecture  

---

## 🛠️ Tech Stack

- **Frontend:** Angular  
- **Backend:** ASP.NET Core Web API  
- **Database:** MongoDB  
- **UI:** Bootstrap / Material Design
